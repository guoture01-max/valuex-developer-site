Privacy Policy

How the ValueX developer website, private application, and proposed HSBC sandbox test handle information.

Developer website

The site serves public information. It has no account sign-in, submission forms, advertising, analytics scripts, or tracking cookies set by ValueX. ValueX provides no website endpoint for processing portfolio data, bank credentials, or authorization responses.

When hosted on GitHub Pages, GitHub logs and stores visitor IP addresses for security purposes. GitHub handles that information under its own privacy statement. GitHub General Privacy Statement

Private ValueX application

ValueX uses portfolio information to calculate and display holdings, transactions, currency conversions, and performance. The app can store entered or imported portfolio records on the device. It can request reference exchange rates and market data from external providers and contact providers for integrations in use. Those services handle requests under their own terms and privacy practices.

HSBC sandbox testing

The planned test uses HSBC sandbox profiles to read selected test balances and transaction history. Sign-in and consent take place in HSBC's sandbox. Any future callback and token handling will take place in a separate test environment. Do not enter real banking information or use live accounts in the test.

Privacy questions

Use the developer contact section for general privacy questions. Keep financial information, personal records, and credentials out of public messages.
